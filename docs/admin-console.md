# 私聊管理控制台

在 `.env` 配置 `ADMIN_QQ=523155725` 后，该账号通过 OneBot 向机器人发送私聊即可管理。留空禁用。只认协议事件中的发送者 QQ，不认昵称、转发、引用文本或消息里自称的身份；群聊和官方通道均不开放管理权限。

`ADMIN_QQ` **不能通过私聊修改**，包括命令、自然语言和小写配置名。要换管理员，必须从部署端编辑 `.env` 后重载。

## 命令和自然语言

| 命令 | 自然语言示例 |
| --- | --- |
| `/help` | 管理员私聊时显示普通帮助和管理员命令；其他用户保持原有帮助 |
| `/admin` | 管理员帮助 |
| `/config list` | 查看 env 中配置 |
| `/config list IMAGE_` | 使用命令按前缀筛选配置 |
| `/config get IMAGE_GEN_MODEL` | 查看生图模型 |
| `/config set TOOL_CALL_NOTICE_SEC 45` | 把工具提示时间改为45 |
| `/config set DEEPSEEK_ENABLE_THINKING true` | 把思考模式改为开启 |
| `/sticker list [关键词]` | 查看表情包列表；查看表情包 熊猫 |
| `/sticker rename old.gif new.gif` | 把表情包 old.gif 改名为 new.gif |
| `/sticker delete old.gif` | 删除表情包 old.gif |
| `/bot log 30` | 看最近30行日志 |
| `/bot reload` | 重载机器人 |
| `/bot stop` | 停止机器人 |

文件名含空格时，命令参数使用引号。自然语言只识别明确的管理意图，无法识别时使用上述命令；不开放任意文件路径、Shell 命令或程序启动。引用里出现的指令不会被当作管理输入。普通聊天继续走原有模型逻辑。

## 表情包

先列出完整文件名，再删除或改名。只操作当前库中已索引的图片，拒绝库外路径、符号链接、目标重名和扩展名变化。改名保留情绪标签、内容哈希、入库及使用记录；需要改检索标签属于另一项操作，单纯改文件名不会改变标签。

操作与采集共用库锁，并同步内存索引与 `index.json`。索引写入失败会回滚文件操作。删除后的图片移入库目录下 `.admin-trash/`，不再参与检索；需要恢复时可通过 SSH 处理。

## 配置与隐私

查看单项时同时显示 `.env` 文件值和当前运行值；未写入文件的项目仍可能采用默认值。密钥、token、secret 默认脱敏，不通过私聊回显原文。

配置更新仅接受项目声明的配置项和单行值。先在独立 Python 进程中校验候选配置，检查通过后备份原文件并原子替换。错误配置不替换原文件，也不污染当前进程。备份位于 `data/admin/env-backups/`，权限为仅部署用户可读写。修改后执行 `/bot reload` 生效；若修改了 OneBot 地址、token 或关闭了通道，重载后可能需要 SSH 修复才能继续私聊管理。

管理消息在普通入站日志、消息队列、引用解析和模型调用之前分流，不写入对话历史或发送给模型。管理审计仅记录动作、账号和结果，不记录配置值。发送日志快照时也会脱敏。

## 程序控制

只适用于 Linux 服务器部署。日志是有界快照，默认 30 行、最多 100 行；内容过长时保留尾部。不会直接运行无限等待的 `start.sh log`。

`reload` / `stop` 先发送受理消息，确认该消息发送成功后，再以独立会话进程执行固定的 `bash start.sh reload` / `bash start.sh stop`。独立进程不随机器人 screen 退出，控制任务以文件锁防止并行执行。它清理继承的项目配置变量，再从文件加载，以免重载后继续使用旧配置。

受理消息不代表操作完成。结果写入 `data/admin/jobs/`，重载后 `/bot log` 会附带最近三项任务状态；若启动失败或机器人已停止，通过 SSH 查看任务记录及日志。任务执行上限为 180 秒，超限记为失败。

`reload` 保留 NapCat 登录，但清空内存历史并中断正在处理的业务。`stop` 沿用现有脚本语义，**同时停止机器人和 NapCat**，之后不能再私聊查看日志或控制；通过 SSH 执行 `bash start.sh` 恢复。本版本不提供私聊启动。
