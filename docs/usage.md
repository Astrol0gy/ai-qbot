# 使用指南


| 操作 | 方式 |
|------|------|
| 和机器人聊天 | 群聊 `@机器人 你的问题`；私聊直接发消息 |
| 查看全部指令 | `@机器人 /help` |
| 清除记忆 | `@机器人 /reset` |
| 图片识别 | 发送图片并 `@机器人`，可附带问题（群里未 @ 的图片机器人也看得见） |
| 表情包 | 发一张梗图就算投喂，机器人自己会收；它想发时会自己挑一张发出来 |
| 地图导航 | 直接问「春熙路在哪」「XX 附近有什么吃的」「从 A 到 B 怎么走」，需要 `AMAP_KEY` |
| 跑团（DM） | `@机器人 我们来玩跑团` |

> 群聊中所有指令都需要 @机器人 才会生效。
