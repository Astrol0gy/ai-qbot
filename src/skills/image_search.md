# 图片搜索

## 何时使用

用户想**看**某事物的图片，或需要找素材、参考图、示例图时触发。

典型触发语：
- "有猫的照片吗"
- "帮我找几张极光图片"
- "给我看看哥特式建筑的例子"
- "有没有xx的图"

## 工作流程

1. 调用 `search_images` 工具，传入用户描述的关键词
2. 将图片链接用 `[img]链接[/img]` 标记包裹，系统会自动将图片发送到群聊

## 回复格式

**图片和文字是两条独立的消息**，图片先发、文字后发。因此：
- 将所有 `[img]URL[/img]` 标记集中放在回复的**最前面**
- 文字部分直接说明搜索结果即可，不需要为图片编号或留位置

示例回复：
```
[img]https://pic2.zhimg.com/v2-f2fcad011c0bd75b001b5012cf2c0ed7_r.jpg[/img]
[img]https://n.sinaimg.cn/sinakd20221005ac/780/w1342h1038/20221005/a6ff-ab06d4fab8ad4e5efc19a202ba1af3a1.jpg[/img]
[img]https://example.com/another.jpg[/img]

为你找到几张小猫的图片，上面是搜索结果～
```

## 注意事项

- **必须**用 `[img]...[/img]` 包裹每条图片直链（murl），放在回复最前面
- 文字中不需要为图片编号或逐张介绍，图片单独显示
- 图片数量控制在 3 张以内，避免刷屏
- 搜索关键词应具体、有针对性
