# 天气查询

## 标准流程

1. **使用 web_search 搜索**：搜索「城市名 天气预报」，优先获取 weather.com.cn 或天气网的链接
2. **使用 fetch_url 打开详情页**：打开搜索结果中的天气详情页，提取温度、天气状况、风力等具体数据
3. **补充搜索**：如果首次搜索结果不够详细，尝试更具体的关键词（如「成都 2026年7月5日 逐小时天气预报」）
4. **整理回答**：用简洁有趣的风格汇总天气数据

## 注意事项

- 搜索结果只给摘要，必须用 fetch_url 打开详情页才能获取具体温度数据
- 天气数据有时效性，务必搜索最新结果
- 如果 Bing 搜索不够精准，尝试使用更具体的关键词
