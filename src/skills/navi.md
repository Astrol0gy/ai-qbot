# 地图导航

两个工具：`search_place` 查地方，`plan_route` 算路线。数据来自高德地图，都是实时查询。

## 坐标怎么传

- 格式固定 **「经度,纬度」**（先经后纬，别写反），高德用的是 GCJ-02 火星坐标系。
- `search_place` 返回的坐标可以直接给 `plan_route` 当起点/终点，这是最可靠的用法。
- 用户只说了地名（「成都东站」）时也可以直接把地名给 `plan_route`——它会自己搜一次换坐标；
  但**不确定的名字建议先用 `search_place` 确认**，否则可能解析到同名的另一个地方。

## 常见问法与流程

**「XX 在哪 / XX 怎么样」** → `search_place(keywords="XX", city="城市名")`，把地址、评分、营业时间讲给用户。

**「XX 附近有什么吃的」** → 两步，别跳步：
1. `search_place(keywords="XX")` 拿到 XX 的坐标
2. `search_place(keywords="火锅", near="刚才的坐标")`（周边搜索按距离从近到远）

**「从 A 到 B 怎么走 / 多久」** → `plan_route(origin="A", destination="B", mode="driving")`。
步行用 `walking`、骑行 `bicycling`、公交 `transit`。用户没说出方式时，按距离判断：
市内短途默认驾车；问「坐几号线」这类才用 `transit`。

**「地铁怎么坐」** → `plan_route(mode="transit", city="成都")`——公交换乘**必须**给城市，
写中文城市名就行（内部会换成高德要的 citycode，也可以直接给 028 这种码）；
跨城时 `city`=起点城市、`city2`=终点城市。

**「尾号限行 / 我的车能走吗」** → `plan_route(..., plate="川A12345")`，
结果里会说这段路有没有限行。**别替高德打包票**：它只给限行提示，能不能走以交管为准。

## 回答风格

- 群里聊天，说人话、短一点：距离 + 耗时 + 关键路段/换乘，不要念一遍完整导航指令。
- 计划值不是实测值：高德的耗时是规划估算（已避开部分拥堵），说明「大约」即可。
- 驾车结果里的「打车约 X 元」是高德的出租车估价，不是网约车实时价，说的时候带个「大约」。
- 用户要地图链接时，可以按 `https://uri.amap.com/marker?position=经度,纬度&name=地点名` 自己拼一个。

## 注意事项

- **`keywords` 只支持一个关键词、不超过 80 字符**（不是多词 AND 检索）。想更准就把词写具体
  （「小龙坎火锅 春熙路店」而不是「成都 火锅 好吃」）。
- **绝不要编造地点、地址、距离、耗时或换乘方案**。工具没给的数据就是没有：
  宁可说「没查到」，也不要凭印象写一个看着合理的答案（地图数据编错会让人走错路）。
- 搜不到地点时，工具会说「没搜到」：换个更具体的说法重试**一次**即可，别反复搜同一个词。
- 报「Key 不正确 / 权限不足 / 今日调用量已达上限」这类错误时是配置或配额问题，
  **重试没有意义**：直接告诉用户「暂时查不了地点和路线」，不要换关键词再试。
- 结果里的评分、人均、营业时间来自高德 POI 数据，可能过期；用户要确认营业状态时提醒一句。
